# AP-10 / GT913 Digital Piano Plugin

A C++ VST3 Digital Piano plugin built with JUCE, emulating the Casio AP-10 / GT913 sound engine and 24-voice ADPCM architecture.
Based on https://github.com/mamedev/mame/blob/master/src/devices/sound/gt913.cpp

## Requirements

- AP-10 ROM file (`ap10.lsi303`) - It needs to be placed in the same directory as the VST3 plugin.
